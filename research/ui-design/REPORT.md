# 前端重设计：两种模式 + 纸面视觉

日期：2026-11-02。目标：把「审计语言 + 修正工具」从面向用户的界面里拿掉，同时把深绿仪表盘换成更干净、
更接近唱片/乐谱的视觉；评测所需的全部工具保留在第二模式。

## 1. 两种模式

| 模式 | 看到什么 | 怎么进入 |
|---|---|---|
| 体验版（默认） | 上传、播放器、主调、全曲时间轴、和弦区间表、分轨入口 | 顶栏 `体验版`，或 `?mode=user` |
| 评测版 | 以上全部 + 来源切换、主调审阅、证据面板、小节编辑器、JSON 导出、评测工具导航 | 顶栏 `评测版`，或 `?mode=audit` |

实现：

- `frontend/modes.js`：读 `?mode=` / `localStorage`，设置 `html[data-mode]`；CSS 用
  `[data-mode=user] .audit-only{display:none}` 与 `[data-mode=audit] .user-only{display:none}` 控制可见性。
- **小节编辑器（bar-editor）在体验版中不挂载**，而不是简单隐藏：它挂载时会把时间轴、和弦表、
  主调审阅移进自己的折叠区，单靠 CSS 隐藏会把用户要看的区块一起藏掉。因此在体验版里拦截
  `BarEditor.open` / `playbackAt` / `toggleLoop`，评测版才放行。
- 切换模式会重载页面（编辑器会重排 DOM），当前歌曲通过 `?project=` 带过去并在重载后自动打开。
  查询参数必须在 `app.js` 清掉 `?session=` 之前读取，所以 `modes.js` 排在脚本最前。

## 2. 视觉

- 新设计层 `frontend/ui.css`，在 `style.css` 之后加载，覆盖旧 token，老页面不受影响。
- 纸面配色：`#f6f3ec` 底、白卡片、`#15140f` 墨色文字、陶土红 `#b4471f` 作为唯一强调色。
- 标题与和弦名改用衬线（Songti/Noto Serif），正文用系统无衬线，时间用等宽。
- 组件：18px 圆角卡片、1px 发丝线、极轻阴影、胶囊形模式开关与段落 chip。
- 时间轴画布改为暖灰波形 + 米色和弦条（原本是深绿），播放头用陶土红。
- 分轨页保留深色「控制台」网格（stems.js 直接在 canvas 里画深色），外围改为纸面：
  纸上的仪表盘，彩色的轨道条反而更突出。
- 结果打开后自动收起营销式的 hero 与上传区，把首屏让给播放器与和弦表。

## 3. 顺带的可用性修正

- 没有和弦的区间不再显示「未覆盖」，播放器显示 `—` 与「前奏」。
- 和弦表在体验版去掉「标记」列与来源长名，标题固定为「和弦区间」。
- 模型徽标在体验版隐藏；评测版顶栏多出工具导航（分轨 / 模型对照 / 根音门控 / 合成复核 /
  音色复核 / 调性标注），链接自动带上当前项目。
- 服务端新增按名返回页面的路由（`/model-review` 等），此前这些页面只能从文件系统打开。

## 4. 验证

- 无头 Chromium：体验版打开《虚拟》→ 62 行和弦、编辑器未挂载、来源区 `display:none`；
  点击「评测版」→ 重载后自动回到同一首歌、编辑器挂载、来源区显示。
- 截图：`30-user-desktop.png`、`31-user-mobile.png`、`20-audit-full.png`、`11-stems.png`。
- 页面无 JS 异常；`node --check` 通过。

## 5. 边界

- 审计页面（model-review 等）自身仍是旧深色样式，只做了路由与导航接入；它们的重设计不在本轮。
- `bar-editor` 的内部组件在评测版沿用旧样式（深色网格），与纸面外壳并置时是有意的「控制台」对比。
- 没有改动识别逻辑、模型、分轨或任何结果数据。

## 6. 分轨控制台（第二轮反馈）

- **播放键**：固定 46px 圆形 + `display:grid; place-items:center`，不再被行高拉成椭圆，播放符号居中。
- **配色**：网格从深绿改为中性炭黑（行底 `#1b1a18` / `#201e1b`，表头 `#232120`），分隔线改为白色低透明度；播放头改陶土红 `#d2653a`，循环条改为琥珀色。面板补 10/12px 内边距。
- **行内按钮**：下载 / M / S 从纯黑方块改为半透明描边胶囊，激活态用陶土红。
- **和弦名进入画布**：新增 26px 画布表头，和弦名按小节列直接画在画布里，与列严格同一坐标系；DOM 标尺只保留小节号。
- **平移与缩放（FL 风格）**：默认按整曲适配宽度（100%），`− / + / 适应` 按钮与 `Ctrl + 滚轮` 以指针为锚点缩放；按住网格拖动即平移，未拖动的点击仍然定位播放。验证：缩放 100% → 182%，`scrollWidth` 1058 → 1928；合成拖拽 200px 后 `scrollLeft` 185 → 370；点击画布 60% 处时钟 00:00 → 02:20 并开始播放。
