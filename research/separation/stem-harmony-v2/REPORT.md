# 分轨构成音和弦 V2：实现、研究与验证

日期：2026-11-01。目标仅为和弦识别，不使用主调约束，不读取用户曲谱或参考标签参与推理。

## 交付和使用

安装版已更新。打开已有歌曲后，结果区点击 **分轨和弦 V2 → 仅识别分轨和弦 V2**。
也可展开“音频与分析设置”，从“音轨分离”的完整流程勾选“同时识别和弦（分轨构成音 · V2）”。
结果保存为独立来源 **分轨构成音和弦 · V2**，可切换、试听、编辑和导出 LAB。
默认保留原时间轴；仅在完整流程明确勾选时替换默认来源。

《虚拟》和《大石碎胸口》都已生成新来源。未使用 Computer Use；浏览器测试在独立无界面 Chromium 中进行。

**功能已完成，但当前实测没有证明分轨提升了真实歌曲的和弦准确率。** 不能把“流程跑通”写成“识别更准确”。

## 研究依据及采取的方法

| 一手论文／实现 | 对本次设计的启发和限制 |
|---|---|
| [Mitoma & Furuya, APSIPA 2025](https://www.apsipa.org/proceedings/2025/papers/APSIPA2025_P307.pdf) | 在 BTC 前用分轨重排声部电平。支持检验伴奏声部的价值，但不是“去除人声越彻底越好”的证明，也不构成所有方法的增益上限。 |
| [Yoshida 等，2026，Source Separation and Remix Models](https://doi.org/10.1007/978-3-032-30573-2_24) | 出版方摘要描述四轨加可学习重混模型；本次未取得全文，不引用无法核验的结果数字。可学习的频率选择与固定后验融合不是同一方法。 |
| [Jointist 论文](https://arxiv.org/abs/2302.00286)、[官方代码](https://github.com/KinWaiCheuk/Jointist) | 乐器条件化转写、分离及其符号证据可用于下游和弦任务。启发本版把“构成音证据”单独送入判断。这里复用 NNLS，而非声称重现或训练了 Jointist。 |
| [NNLS-Chroma / Chordino 官方实现](https://github.com/c4dm/nnls-chroma) | 提取近似音符能量，减少直接把泛音当独立音高的问题。本版调用项目已安装的官方插件，记录工具与变换的哈希。 |
| [BTC 官方实现](https://github.com/jayg996/BTC-ISMIR19) | 提供声学模型和 CRF 的可复现参考。它不是现有冻结模型，直接替换会同时改变词表与基线；这轮未把模型替换混作分轨增益。 |
| [ChordFormer](https://arxiv.org/abs/2502.11840) | 结构化区分根音、低音和和弦类别。启发低音只作为支持证据，不能硬性要求最低音等于根音。没有在此版本引入其权重。 |
| [Daniel Ko 的作者实验记录](https://ko28.github.io/chord-transcription/) | 分轨训练并不必然优于原混音，是必须保留对照和负结果的直接例子。 |
| [Higher-Order Harmonic Language Modelling](https://arxiv.org/abs/1808.05341) | 和弦身份与持续时长应分别建模。本版保留现有时序解码的边界提案，避免把每个琶音误作换和弦。 |
| [SheetSage2, 2026](https://arxiv.org/abs/2610.05336)、[公开模型与代码](https://huggingface.co/m-a-p/SheetSage2) | 新近的合成监督与结构化解码方案，已纳入后续参考；本轮没有下载或运行，不引用其排行榜结果为本地增益。 |

本版没有新增第三方权重，也没有训练新神经网络。它是一个可运行的声部证据融合流程。

## 实际流程

1. 复用当前冻结模型的原混音后验和完整段边界；已有分析不重算主调。
2. 按所选版本复用分轨，缺少时由已有分离器生成。
3. 六轨时使用 `other + guitar + piano` 作为伴奏、`bass` 作为独立低音；四轨使用 other 和 bass；两轨版本使用 instrumental，并明确缺少独立低音。
4. 以原电平合成浮点 WAV，不按每条轨归一化，也不把微弱串音放大到与主要声部等权。校验来源哈希、声道、采样率和时长。
5. 对伴奏与低音分别提取 NNLS 音符证据。以实际时间重叠量聚合到候选和弦段，伴奏提供构成音，低音提供根音／转位支持。
6. 对 12 根音 × 10 类和弦重评分。原完整段结果作为上下文先验；关闭声部证据时必须还原原结果。低音不是硬性根音约束。评分为未校准排序值，不当作准确率。
7. 无和弦 N 只来自原混音模型，不能因为去掉人声后伴奏安静而制造 N。首尾用原混音证据补齐覆盖；短于三小节的片段显式使用原模型区间，并记录边界策略。
8. 新结果以内容哈希生成来源 ID，保持旧来源与修订有效；记录输入分轨、模型、代码、边界模型和后验身份。

注意：没有自动把“吉他旋律／伴奏”的估计子轨当作确定角色。该模型可能把同一把指弹吉他拆开；当前用完整吉他参与伴奏证据，保留风险说明。

## 旧实现中确认的问题

- 原混音 985 个区间，和声轨 989 个区间，却截取最短长度后按下标融合。同一下标起点最大差 **0.85 秒**，不能视为同一帧。
- `duration / count` 生成均匀格不符合真实分段时钟。
- 把两路 N 的最大值作为结果，会把分离后缺失的声部误当成原曲无和弦。
- 旧评分在每个预测段重新起 0.25 秒网格，并跳过无输出区间：分母随预测改变。
- 旧完整流程调用 `watchJob()` 后立即显示完成，但它内部是轮询调度，不是等待任务结束。
- 旧报告中的“换输入路线的上限只有零点几个百分点”不能由有限论文或单曲结果推出。

新流程不走旧的下标融合和静默换解码器路径。旧融合模块保留用于历史实验，默认任务转入 V2。
另做了纯研究对照：修正旧融合的时间对齐，在同一完整段解码器下测 λ=0、0.25、0.65。
准确率分别为 68.16%、67.77%、65.45%。修正后仍未超过基线，但退步幅度不能照抄旧报告。
见 `check_legacy_alignment.py` 和 `aligned_legacy_scores.json`。

## 测量结果与解释

按参考区间内的真实重叠秒数评分；漏输出计错，不在每个预测段重置采样网格。
边界容差 0.5 秒，一对一匹配。参考标签只由独立评测脚本读取。

| 材料 | 原完整段输出 | V2 | 正确解释 |
|---|---:|---:|---|
| 《虚拟》参考覆盖 228.92 秒，完整和弦标签 | 68.16% | 68.16% | 持平，没有验证到分轨增益 |
| 《虚拟》根音 | 87.42% | 87.42% | 持平 |
| 《虚拟》边界 F1 | 90.16% | 90.16% | 核心边界沿用基线，不应声称改善换和弦定位 |
| 合成 C–Am–F–G，16 小节 | 93.59% | 99.84% | 原完整段只覆盖 93.74% 的参考时长；提升来自补齐开头 |
| 合成对照：先补齐覆盖，再关闭声部证据 | 99.84% | 99.84% | 分轨没有贡献额外正确标签 |
| 《大石碎胸口》，约 7 分钟 | 无人工真值 | 162 段 | 仅为真实录音运行验证，不报准确率 |

《虚拟》的首版重评分结果为 64.93%；其原始概率先验可能推翻完整段已有的正确判断。
加入“无新增证据必须为恒等变换”的性质修复后得到上述最终结果。这是开发数据，不能称为盲测。
没有扫描参数以挑选《虚拟》最高分。初版结果保存在 initial_result.json / initial_scores.json。

当前保守权重下，两首真实歌的已覆盖有和弦区间没有改成新的和弦标签；主要变化是首尾覆盖及原混音 N 的处理。
因此本版交付的是后续可验证、可替换评分器的完整流程，而不是已经证实有效的精度升级。

## 下一步应如何证明提升

应在曲目互斥的训练／验证／测试集上学习“原混音、伴奏、低音”的可靠性及构成音评分，而不是继续用《虚拟》试系数。
真实分离器输出也必须进入训练，不能只在理想干净 MIDI 伴奏上拟合。
需要包含转位、踏板低音、复杂九和弦、琶音、弱伴奏、失真吉他和真正快速换和弦的材料；
分别报告根音、三和弦、七／九和弦、N、覆盖率、边界以及过分割。
如果要改进边界，需训练／验证对应声部特征的边界模型，而非直接把现有混音特征分类器套到另一分布后宣称更准。

本版的音符缓存、逐段 diagnostics.json、独立来源和固定评测脚本可复用，且不需要人工标签进入实际识别过程。
