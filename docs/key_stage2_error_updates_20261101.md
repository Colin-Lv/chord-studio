## KEY-021 · 扩展音解析不完整

证据：[parser_followup.json](D:/ChordStudio/research/key-stage2-20261101/parser_followup.json)。原解析器对Cmaj9、Dm9遗漏显式九音，对G♯add9解析失败。

影响：此前“完整和弦音的调内占比”只能理解为“解析器实际保留音的占比”；不能据此推断原和弦中不存在某音。涉及《虚拟》的精确占比需在修复解析后重新计算。

状态：已复现，尚未修复。未混入已冻结的语义消融。

防复发：用显式期望音集合检验9、add9、11、13、转位与别名；未知后缀不得静默变成另一个已知和弦；解析变化与评分变化分别做对照。

## KEY-022 · 未验证的时间坐标会污染结构与声部证据

证据：[structure-packet/packet.json](D:/ChordStudio/research/key-stage2-20261101/structure-packet/packet.json)。原MIDI的拍号元数据不一定是外部人工结构标注使用的小节单位；005的处理后旋律与原MIDI还存在内部时间差，不能只靠一个全局偏移解决。

状态：本轮数据接入已防止错误映射；005没有附加原MIDI时间及钢琴最低音代理。其他7首保留匹配覆盖率和残差，不能将这项近似映射视为逐音人工对齐真值。

防复发：来源坐标、单位、起点、版本必须明确；用音符序列与时间残差核验，不因标题相同就合并。未通过映射的材料保持独立坐标，不使用强行补齐的音符证据。
