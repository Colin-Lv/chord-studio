## 主要变化

### 工作区与阅读

- 三栏工作台：段落导航 / 和弦谱 / 标注检查器。导入、段落和和弦编辑分别呈现，原先连续堆叠的长侧栏被改为标签页和折叠区。
- 歌曲全局结构时间条、段落分隔、小节号、当前和弦与局部调性、逐拍指示与小节内播放线。
- 和弦名 / 级数切换，舒适 / 紧凑 / 放大三种密度，可隐藏逐拍格，按低证据片段筛选。
- 深浅主题、键盘可达控件、焦点跟随选中片段、减少动画偏好、打印样式。
- 待复核筛选后的方向键仅在可见小节内移动，避免选中屏幕上已隐藏的片段。
- 文件面板支持打印 / 保存 PDF，保留当前筛选和和弦名 / 级数显示；A4 排版包含标题、调性、拍号、速度、段落和人工修改标记，隐藏播放控件和手机抽屉。已修复 Chromium 对长 grid 的首张空白打印问题。
- 有 `key_estimation` 时可查看全局调性前四候选、前两候选分差与估计音频范围。分值明确未经正确率校准；局部转调时间线优先显示，查看候选不会改写调性。
- 支持 `display_title`，展示歌曲名时不改动实际 `audio_file` / `source`。整曲拍号未知、只有未定位区间时按秒级片段卡片呈现，保持可读和可播放，不把整曲画成一个假小节。
- 每小节优先读取 `bar.meter` / `bar.beats_per_bar`，播放时同步局部拍号和拍点指示。3/8 对应 6 个十六分位置；`incomplete` 只显示实际观测拍点，不补虚假拍点。铺谱跳过不完整网格而保留后续小节的原始谱序号。
- 专家拍格审查副本在顶部明确提示“尚需人工核对”，拍点不完整的原生分析也有可见提示。
- 390px 窄屏无横向溢出。手机使用底部标注入口和抽屉，避免编辑器被放在上百小节之后；抽屉有焦点约束、背景隔离和关闭按钮。

### 播放与定位

- 以 `audio.currentTime` 为唯一播放时钟，使用 `requestAnimationFrame` 刷新视图；循环与试听终点另有轻量计时保护。
- 保留原音频偏移 `audio_offset`，校准偏移应用于分析坐标；从谱格跳转时反向补偿偏移。
- 单击只选择与定位，保持原播放状态；空格播放 / 暂停，双击进入和弦编辑。
- 变速保留音高；自动跟随播放，用户手动滚动后暂停跟随 5 秒；手机编辑抽屉打开时不滚动背后谱面。
- 总览点击跳转、拖动设置 A/B 区间；可循环片段、段落和识别出的和声循环；支持只试听选中片段。
- 点击时间读数或按 `G` 输入 `01:23.450` / 秒数进行精确定位。
- 支持 `#t=起始秒&end=结束秒` 链接。打开后定位对应片段并标出 A/B 范围，保持暂停且不更改标注；按空格播放、按 L 开启循环。时间使用分析坐标，并正确补偿音频偏移和画面校准。
- 原音频路径失效时可选择本地音频重新连接，继续标注；解码后显示真实波形。未连接波形时，时间条明确显示和弦证据总览。
- 支持 `audio_waveform` 真实峰值包络，默认打开即可显示波形；前端校验版本、时长、音频偏移和数值范围，导入、撤销时同步刷新。手动选择音频后使用浏览器解码全部声道并按全局峰值归一化，覆盖旧波形。

### 人工修改的可靠性

- 撤销 / 重做覆盖和弦、切分、边界、粘贴、铺谱、导入、段落、重建事件与全部还原。最多保留 60 步，并限制历史快照字符总量，避免长曲占用无限内存。
- 编辑单拍不再把整小节重建成拍级格子，其他位置已有的 8 分 / 16 分边界保留。
- 拆分仅在选中时间范围内部进行，按真实拍点切分，避免扩展到相邻和弦。
- 边界编辑同步移动相邻片段，保持小节内连续；支持在播放头切分。
- 还原通过原时间范围恢复原标注与分段，不再使用会随切分变化的事件数组下标。
- 修复选中高亮残留，跨小节事件在各小节内可以正确定位、高亮和改和弦；逐拍修改跨小节事件时按时间裁剪保留两侧，不产生重叠事件。
- `grid_status='uncovered'` 的头尾区间显示“拍点未定位”，不伪造拍格、不计入已定位小节数；可以修改和弦。
- 修复罗马输入中的大小写与和弦性质，例如 `II7 → D7`、`ii7 → Dm7`、`Imaj7 → Cmaj7`（C 大调）；修复 `6m7` 的重复小调后缀。
- 根据 `key_timeline.segments`、`modulations` 和 `bar.local_key` 解析局部调性；转调后的铺谱、绝对和弦粘贴重新计算对应罗马标注，不把整首歌强制视为初始调。
- 建议仅能跳转或填入编辑器，必须点击“应用”才写入；模型分值显示为证据分值，明确不等于正确概率。
- `weighted_temporal_support` 明确解释为时间段内标签的支持程度。SheetSage2 的 `not_exported_by_model` 显示“证据未提供”，不把占位数值 0 误解为模型低分；未知证据使用灰色标记。
- 证据含义在检查器中直接可见，手机不必依赖悬停提示；结构角色明确为专家模型建议，缺少边界激活时显示证据未提供，角色候选使用中文名称。

### 导入、导出与结构

- 新增完整 analysis / corrected JSON 导入，独立于“从和弦文本铺谱”。完整导入保留所有未知元数据、网格信息、顶层与嵌套 provenance，音频连接继续使用当前已确认的同曲来源。
- 校验音频文件标识、时长、音频偏移以及嵌套时间片段，避免把不同歌曲或非法嵌套内容装入当前工作台。
- 段落支持名称、主歌 / 副歌 / 前奏等角色、范围编辑、新划分、并入相邻段落和循环试听。边界编辑同步相邻段；新划分保留左右剩余区间；缺少原结构时用明确的“未分段”占位，使完整列表始终连续覆盖谱面。
- 只修改段落名称或角色时保留原秒级边界，兼容两个段落共享同一个边界小节。
- 保留编号为 0 的未定位头部区间；修复首段改名时表单误回退到第 1 小节的问题。导航显示未定位区间而非“第 0 小节”，编辑位置不再直接显示长浮点拍号。
- 人工结构写入 `source='manual'`；`structure.manual_overrides` 保存完整段落列表，支持结构模块再次分析时保留人工分段。
- 同步更新 `structure.boundaries`，首次人工修改保留原 `automatic_sections` / `automatic_boundaries`，不把模型证据分值强制升为 1。前端导出的边界调整、新划分、合并和无结构起步案例已实际通过后端 `apply_manual_sections` 往返校验。
- 自动角色与人工确认明确区分；专家模型的 `S` 编号用于定位，不被当作音乐重复关系。
- JSON 保留完整结构与 provenance；增加段落 CSV；保留原 LAB 导出。
- 草稿按音频标识和完整原始分析内容指纹隔离，包含 provenance、证据分值与嵌套拍网格；即使新模型给出的和弦相同，也不会与旧模型共享草稿。旧版草稿恢复时明确提示来源可能不同。
- 导出 HTML 内联全部 CSS、JS 和分析 JSON，不依赖 CDN、在线字体或网络服务。音频仍为外部文件，可随时重新选择。
- 导出时转义 `< > &`，避免文件名 / 标签中的 `</script>` 破坏页面；音频相对 URL 编码 `#`、`%`、空格和中文，跨盘符使用文件 URI。

## 真实数据一致性发现

`laonanhai_user_corrected_final_analysis.json` 中有两套冲突事件。工作台发现 74 处事件重叠、51 个覆盖区间与小节谱格不同，例如：

| 时间区间（秒） | events 标签 | bar.spans 标签 |
| --- | --- | --- |
| 156.038–157.710 | A7 / F | F |
| 157.710–159.359 | F / G | G |
| 179.397–181.069 | C / F | F |

工作台不会自动选择哪套标签正确。冲突页可审阅和导出；和弦编辑暂时禁用。使用者明确点击“以小节谱格重建事件时间轴”后才重建，可撤销回到完整原冲突状态。此操作没有写回原始参考文件。

一致性检查比较时间覆盖和绝对和弦标签，不要求 events 与各小节裁剪出的 spans 一一相同，因此合法的跨小节事件不会被误判。

详见 [浏览器实际冲突审阅记录](../benchmarks/reports/session_20260926/studio_timeline_audit.json)。

## 实际限制

- HTMLMediaElement 的 A/B 循环以浏览器媒体时钟执行，可能受解码和后台计时节流影响；不是采样级无缝循环。
- 跨小节事件与未定位区间可以改和弦；秒级边界调整仅在拍点完整的单个小节内进行，至少保留 20ms 且不能越过整个相邻片段。跨小节事件可先通过逐拍局部编辑划分。
- 分析内含有效 `audio_waveform` 时直接显示峰值包络；否则需手动连接音频进行浏览器解码。手选音频超过 120MB 时保留证据总览，以限制内存占用。
- 前端不会重新运行结构模型。手工修改和弦后，原结构 / 循环结果仍是模型给出的参考，需要单独重新分析才更新。
- 页面显示已有全局与局部调性，候选查看仅针对全局调性；也可从完整 JSON 导入调性标注，没有页面内调性编辑器。和弦 / 级数输入会使用已有局部调性。分歧清单基于原模型结果，不会随浏览器草稿修改自动重算。
- 自动保存受浏览器配额影响；失败时会明确提示导出 JSON，不能替代独立文件备份。
- 前端完整性与可校正性改善不等于识别模型准确率提升，识别指标由独立评测记录给出。
