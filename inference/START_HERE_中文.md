# Chord Studio 本地音频测试

这是已冻结和弦研究模型的本地入口。模型权重未重新训练，应用默认模型未替换。

## 直接使用

1. 保持这个文件夹完整，双击 `Run_Chord_Studio.cmd`。
2. 在出现的窗口粘贴音频完整路径；也可以把音频文件拖入该窗口，然后按回车。
3. 等待出现 `successful: true`。本文件夹的 `results` 下会产生一个带时间戳的新目录；重复测试不会覆盖以前的结果。
4. 打开其中的 `结果说明.txt` 或 `chords.csv`，查看开始秒、结束秒、和弦和置信分数。`quick_result.json` 还记录入口版本、模型版本、权重指纹和限制。原始 `prediction.json`、`prediction.lab`、`posterior.npz` 也保留。

也可在 PowerShell 中运行（将音频路径换成自己的文件）：

```powershell
& 'C:\Users\33573\miniconda3\python.exe' -I -B '.\test_audio.py' --audio 'C:\音乐\歌曲.wav'
```

建议先用一段不超过5分钟的本地音频。此入口默认限制300秒，首次运行会生成声学缓存，之后复用。它使用这台电脑已安装并已验证的 FFmpeg、Sonic Annotator/NNLS、madmom 和 Python；没有联网下载、自动安装或改系统配置。复制到其他电脑前需要配置对应运行工具，压缩包不是通用独立安装程序。

## 如何理解输出

- 和弦格式如 `C:maj`、`A:min7`；`N` 表示模型判断为无和弦。
- 置信分数不是识别准确率，也未经校准。和弦分数为该根音/性质的条件后验乘以 `(1−N概率)`，N分数为N头的概率；合并分段按各声学小区间的时长取平均。CSV还给出区间内最小/最大分数，方便发现段内不稳定性。
- 斜杠低音可能沿用前端估计；这里的置信分数不衡量低音可靠性。
- 支持十类：`maj/min/7/maj7/min7/9/maj9/min9/sus2/sus4`，以及N。`5`、`13`、`dim7`等词表外类型可能被归为现有类别，模型没有可靠的“未知类型”检测能力。
- 参考无和弦（N）时间被误判成和弦的比例仍明显偏高；封账外部评价为77.474%。此入口不输出或认证小节、乐段、循环、完整调式；较高分数也可能错误。

## 已完成的最小验证

用一段已有12.907秒开发音频，经过含中文、空格、`&`的带引号路径输入，完成冷缓存全流程，生成16段。分段与原v82逐项一致、权重相同，置信分数的独立时长汇总误差小于 `1.2e-16`。这是程序可用性验证，没有读取参考和弦标签，也不是新增准确率评价。`example_output` 只附这次输出文本，不附源音频。

遇到错误时窗口会显示“测试未完成”，输出目录保留日志；只有 `run_status.json` 中 `successful=true` 才代表原始推理完成。常见原因是音频不存在、超过时长限制、工具路径失效或可用内存不足。

完整原始技术说明保留在 `README.md`；研究结果与数据口径见 `研究结果摘要.md`。
